# Gold’s Gym Admin Dashboard

## Project Overview

This project focuses on designing an **Admin Dashboard for Gold’s Gym** to help the Admin Head quickly monitor gym performance and manage day-to-day operations.

The dashboard brings important information such as visitors, trainers, sessions, equipment status, membership progress, and class occupancy into one place. This reduces the need to check different records separately and makes important information easier to understand at a glance.

## About the Brand

Gold’s Gym is a global fitness brand known for its strong and energetic fitness identity.

The visual design of the dashboard follows the brand’s existing identity:

* **Gold/Yellow** – primary brand colour
* **Black** – creates contrast and strength
* **White** – supports readability and balance
* **Bold, uppercase typography** – reflects the powerful and sporty personality of the brand
* **Strong geometric elements** – maintain the visual language of the brand

## Target User

The primary user of the dashboard is the **Admin Head of Gold’s Gym**.

The dashboard is designed for someone who manages overall gym operations and needs to monitor staff, members, sessions, and facilities regularly.

## Dashboard Goals

The main goal is to help the Admin Head:

* Monitor overall gym performance
* Track daily visitors and activities
* Check trainer availability
* Monitor class occupancy
* Identify equipment that needs maintenance
* Track membership progress
* Make faster day-to-day decisions

## Key KPIs

The dashboard tracks the following important KPIs:

* **Total Visitors** – shows gym footfall
* **Workout Sessions & Class Occupancy** – shows session usage and available capacity
* **Total Trainers** – shows staff availability
* **Machine Status** – shows equipment condition
* **Membership Target** – shows progress towards the membership goal

## Visualisation Choices

Different visualisations were selected based on the type of information being displayed:

### KPI Boxes

Used for important numbers that need to be understood quickly.

### Tables

Used when multiple details such as names, status, sessions, and service dates need to be viewed together.

### Capacity Bars

Used to show occupied seats compared with total class capacity, making full and nearly full classes easy to identify.

### Half Doughnut Chart

Used to show progress towards the membership target.

### Calendar

Used for date-based information and upcoming schedules.

### Line Chart

Used to show visitor trends and changes over time.

### Doughnut Chart

Used to compare the proportion of visitors across different age groups.

## Design Process

The project was developed through the following stages:

1. **Brand Study** – Understanding Gold’s Gym's colours, typography, logo, and visual identity.
2. **Dashboard Planning** – Defining the purpose, target user, goals, and KPIs.
3. **Rough Sketches** – Exploring different layouts and ways of organising the information.
4. **Dashboard Design** – Developing the final visual layout using the selected brand style.
5. **Action Demonstration** – Showing how the dashboard information can support administrative decisions.
6. **Visualisation Justification** – Explaining why each chart, table, and component was selected.

## Expected Use

The dashboard is intended to be checked **daily by the Admin Head** and can be referred to throughout the day to monitor ongoing gym operations. Weekly information such as membership progress and visitor trends can also be reviewed to understand changes over time.

## Project Outcome

The final dashboard combines **Gold’s Gym’s bold visual identity with clear data visualisation** to create an admin-focused interface that makes important gym information easier to monitor and act upon.
